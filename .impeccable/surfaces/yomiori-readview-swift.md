# Content-first library

Scope: Read, Documents, Dictionary and Coach. Mode: Operate/Read. The user reads and learns on an iPhone in changing light; washi paper and sumi-night grounds follow system appearance.

## Direction contract

THESIS: Reading content establishes identity; remove repeated branding and generic empty-state scaffolding.

OWN-WORLD: Native Apple library grammar on the icon's world: washi paper, sumi ink, matcha tint, shu bookmark, sakura highlight; SF interface type and New York/Hiragino Mincho book type. System glass only in navigation/presentation.

STORY: Open current material, import personal sources, collect words, then practice.

FIRST VIEWPORT: One native large title. Read opens with a large original-text excerpt and resume link, followed by compact source previews. Documents show actual page covers. Dictionary puts search/tabs directly below the title, then prominent terms. Empty Read exposes source choices. Coach combines configuration into one menu and offers editable conversation starters above its composer.

FORM: User-pinned Apple-native content-first direction, delegated explicitly; no random concept selection. Signature interaction: original-text preview opens its existing reader through the native navigation transition. Respect Reduce Motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
