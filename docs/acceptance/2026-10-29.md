## 可重复执行

应用此后已更名为 Yomiori；下列重跑命令与源码路径已同步，历史产物路径保留原名。

`YomioriUITests/ComponentAcceptanceTests.swift` 已加入共享 scheme。完整测试会运行 48 项 Swift Testing 测试与以下 4 项 XCTest UI 测试：

- `testMarkdownAndStreaming`
- `testReaderLookupAndNativeSelection`
- `testSettingsLicenseEntry`
- `testSystemShareCancelThenSaveToFiles`

```sh
DEVELOPER_DIR=/Applications/Xcode-27.0.0.app/Contents/Developer \
xcodebuild -project Yomiori.xcodeproj -scheme Yomiori \
  -destination 'platform=iOS Simulator,id=D11C224D-313C-408F-90DE-6D641B25D992' \
  -derivedDataPath /tmp/kotoba-review-derived \
  -disableAutomaticPackageResolution -parallel-testing-enabled NO \
  CODE_SIGNING_ALLOWED=NO test

DEVELOPER_DIR=/Applications/Xcode-27.0.0.app/Contents/Developer \
xcodebuild -project Yomiori.xcodeproj -scheme Yomiori -configuration Release \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/kotoba-review-derived \
  -disableAutomaticPackageResolution CODE_SIGNING_ALLOWED=NO build
```

验收期间修正了测试定位与等待条件：导出按钮使用 `export.primary` 标识；iOS 27 分享动作按 Cell 定位；文件名使用唯一值避免重复运行时冲突；以应用成功消息确认投递完成后才返回。添加 Debug 预览的 exported 数量用于检查持久化标记，没有替代系统分享回调。
